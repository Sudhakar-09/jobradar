JobRadar will read job-alert emails in your Gmail account, with read-only access.

- It only looks at emails from the job boards you set up alerts with (LinkedIn, Naukri,
  Naukrigulf, Bayt, GulfTalent, Instahyre, Foundit) and only from the last few days.
- It keeps the jobs it finds (title, company, location and link) and the email's ID so it never
  processes the same email twice. It never stores the email text, and it never reads other mail.
- It cannot send, delete or change anything in your mailbox.
- You can disconnect at any time; access stops immediately and the stored access token is deleted.
